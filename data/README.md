# Datasets

The datasets are not redistributed here. Download them and place them as follows.

## MotionSense

- Source: https://github.com/mmalekzadeh/motion-sense (Malekzadeh et al.)
- Download `A_DeviceMotion_data.zip` from the repository's `data/` folder and extract it so that you have
  `data/motionsense/A_DeviceMotion_data/<activity>_<trial>/sub_<n>.csv`.
- Or set `MOTIONSENSE_DIR` to the folder that contains `A_DeviceMotion_data`.

## WISDM Activity Prediction v1.1

- Source: https://www.cis.fordham.edu/wisdm/dataset.php (Kwapisz, Weiss, Moore)
- Download `WISDM_ar_latest.tar.gz`, extract it, and copy `WISDM_ar_v1.1_raw.txt` to `data/`.
- Or set `WISDM_FILE` to its path.
- The WISDM license asks that its `readme.txt` accompany any copy of the data and that the dataset paper be cited.
